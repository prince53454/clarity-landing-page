# Clarity — Finance made simpler

A responsive landing page for tax and financial compliance support. Built with plain HTML and CSS using the supplied Figma design and image assets.

## Run locally

From this folder, start any static web server. For example:

```powershell
python -m http.server 8765
```

Then open <http://localhost:8765>.

## Design source

The original Figma file is `FIGMA.fig`. The supplied image and icon files are in `Assets - Images & Icons-20261113T123316Z-1-001/`.
